# Agent: GitPulse Documentation System

## How to use this project:
- Always read `project_memory.md` FIRST for current status and core context.
- Use core files (`architecture.md`, `dev_log.md`, `tasks.md`) as primary sources for information.
- Only read deeper files in `research/` or `archive/` if specific historical or technical exploration is needed.

## 🔁 COMMAND: UPDATE_MEMORY
When the instruction "UPDATE_MEMORY" is given, you MUST:
1. Analyze recent code and documentation changes.
2. Update `project_memory.md`, `dev_log.md`, and `tasks.md`.
3. Reflect new features, architecture changes, and updated status.
4. Remove outdated information and keep the documentation concise.
5. Never duplicate content between core memory files.
