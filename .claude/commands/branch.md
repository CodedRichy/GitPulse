---
name: branch
description: AI-powered branch management
---

Create, switch, delete, list, or rename branches with AI-suggested names based on changes.

## Usage

```
/branch <subcommand>
```

## Subcommands

- `list` - List all branches
- `create [name]` - Create new branch (AI-suggested if no name)
- `suggest` - Get AI-suggested branch name
- `switch <name>` - Switch to branch
- `delete <name>` - Delete branch
- `rename <old> <new>` - Rename branch
