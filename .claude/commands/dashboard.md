Open the GitPulse web dashboard in your browser.

## Usage

```
/dashboard [--port <number>]
```

## Options

- `--port` - Custom port (default: auto)

## Features

- Quality metrics over time
- AI commit statistics
- Activity heatmap
- Team analytics (Pro/Team)
- API key management
- Settings sync

## Note

Requires Pro or Team subscription for cloud features.
