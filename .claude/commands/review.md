---
name: review
description: AI code review with quality analysis
---

Perform AI-powered code review on staged changes or specific files.

## Usage

```
/review [target]
```

## Targets

- `staged` - Review staged changes (default)
- `unstaged` - Review unstaged changes
- `<file-path>` - Review specific file

## Analysis Includes

- Code quality issues
- Security concerns
- Performance bottlenecks
- Style violations
- Improvement suggestions
