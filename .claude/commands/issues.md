---
name: issues
description: Issue tracker integration (GitHub/Linear/Jira)
---

Interact with issue trackers to link commits to issues.

## Usage

```
/issues <command>
```

## Commands

- `list` - Show open issues
- `show <id>` - Display issue details
- `link <id>` - Link current branch to issue
- `create <title>` - Create new issue

## Supported

- GitHub Issues
- Linear
- Jira
