# Assets Directory

This directory contains application assets for packaging.

## Required Icons

- `icon.ico` - Windows icon (256x256)
- `icon.icns` - macOS icon (512x512)  
- `icon.png` - Linux icon (512x512)
- `dmg-background.png` - macOS DMG background (600x400)

## Placeholder

For development, you can use placeholder icons. For production:
1. Create a professional GitPulse logo
2. Generate icons in all required formats
3. Place them in this directory

## Tools

- Online: https://favicon.io/
- macOS: iconutil (built-in)
- Windows: GIMP, Photoshop
